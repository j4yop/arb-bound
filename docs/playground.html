What this page does and does not prove

  • Proves: the pipeline is real code that runs on input it has never seen. Paste rows that contradict the thesis and the verdict will change, because it is computed, not recalled.
  • Proves: it runs offline. Once the Python runtime has loaded, the analysis itself is local — no server, no API, no key.
  • Does not prove: a tradeable edge. Settlements are not fills; that caveat is in the report itself, along with the sensitivity of every assumption.
